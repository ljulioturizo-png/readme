# WIJITECH 2.0

## Descripción

WIJITECH 2.0 es un sitio web orientado a la prestación de servicios
técnicos y cursos relacionados con el área tecnológica.

La página permite a los usuarios conocer los servicios ofrecidos,
consultar información sobre los cursos disponibles y comunicarse con
WIJITECH para solicitar información o atención.

## Características

- Servicios técnicos a domicilio.
- Información sobre cursos técnicos.
- Información sobre validación de bachillerato.
- Atención mediante WhatsApp.
- Información sobre los servicios ofrecidos.
- Diseño web adaptado para facilitar la navegación.
- Información de contacto para los usuarios.

## Servicios

El sitio web presenta información relacionada con:

- Servicios técnicos a domicilio.
- Cursos técnicos.
- Validación de bachillerato.
- Atención y soporte para los usuarios.

## Uso

Para utilizar el sitio web, el usuario debe ingresar a la página y
navegar por las diferentes secciones disponibles.

Desde la página principal se puede consultar la información de los
servicios y cursos y utilizar el botón de WhatsApp para comunicarse
con WIJITECH.

## Instalación

Este proyecto puede ejecutarse desde un navegador web.

Para utilizar el proyecto de manera local:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo principal de la página web en un navegador.
4. Navegar por las diferentes secciones del sitio.

También se puede acceder al sitio web publicado mediante GitHub Pages:

https://wilin34.github.io/wijitech2.0/
